我整理後，**你的研究主軸不要改**，定位只是一個**衍生功能（Extension）**。因此定位的目標不是「發明新的定位演算法」，而是：

> **利用飛控已有硬體與感測器，在不增加任何額外硬體的情況下，提高 BLE RSSI 室內定位精度。**

這樣與你的論文主題最一致。

---

# 一、定位設計原則（★★★★★）

## 不增加任何硬體

維持目前系統：

* Seeed Studio XIAO nRF52840 Sense（飛控）
* XIAO ESP32S3（Gateway）
* ATK MiniFly（nRF51822）
* BLE
* ESP-NOW
* Ground Station

**不增加：**

* UWB
* Camera
* LiDAR
* Optical Flow
* ToF

---

## 利用飛控已有資訊

你的移植版已經具有：

* IMU（Acc、Gyro）
* Roll / Pitch / Yaw
* BMP280 高度
* Motor Thrust (`powerGetLastThrust()`)
* Motor PWM
* RC Command
* 飛行狀態（Airborne 判斷）

這些都是一般 BLE Beacon 沒有的優勢。

---

# 二、最值得保留的定位策略

## ① 2D 降維定位（★★★★★ 最推薦）

不要解算三維。

因為：

高度已經由：

```text
BMP280 + IMU
```

提供。

BLE 只需要：

```text
(X,Y)
```

高度：

```text
Z = Flight Controller
```

優點：

* 計算量降低
* RSSI 誤差降低
* 系統更穩定

這也是最符合你的飛控架構。

---

## ② RSSI Calibration（★★★★★）

每一塊板子的 RSSI 都不同。

例如：

```
ATK
1m=-65dBm

XIAO
1m=-60dBm

ESP32
1m=-58dBm
```

因此：

每個節點建立：

```
RSSI Calibration Table
```

而不是：

全部使用同一個 Path Loss Model。

---

## ③ RSSI Outlier Removal（★★★★★）

RSSI：

```
-60
-61
-59
-91
-60
```

直接：

去除：

```
-91
```

再計算。

比直接 Kalman 更有效。

---

## ④ Dynamic Anchor Selection（★★★★★）

例如：

```
Anchor1  -52
Anchor2  -56
Anchor3  -63
Anchor4  -88
```

不要四個都算。

只使用：

RSSI 最穩定的三個。

---

## ⑤ Weighted Trilateration（★★★★★）

不是：

普通三邊定位。

而是：

RSSI 越穩：

權重越高。

例如：

```
Weight = 1 / RSSI Variance
```

這個很容易實作。

---

# 三、利用飛控資訊改善定位（你的特色）

這是我認為最重要的地方。

---

## ⑥ Motion-aware Sampling（★★★★★）

你的飛控知道：

```
powerGetLastThrust()
```

因此：

例如：

懸停時：

```
RSSI Sampling
```

高速飛行：

降低權重。

這比一般 Beacon 更有優勢。

---

## ⑦ Tilt-aware Weighting（★★★★★）

飛機：

Pitch：

40°

BLE 天線方向改變。

RSSI：

自然下降。

因此：

```
Pitch > Threshold

↓

RSSI Weight ↓
```

而不是：

直接相信 RSSI。

---

## ⑧ IMU Validation Gate（★★★★★）

BLE：

算出：

```
(1.2,1.3)
```

下一筆：

```
(2.8,0.5)
```

IMU：

卻顯示：

沒有加速。

直接：

```
Discard
```

不用完整 EKF。

只做：

Validation。

實作難度低。

效果很好。

# 六、論文可以強調的重點（不是創新演算法，而是系統整合）

你的定位章節建議強調：

1. **利用飛控既有感測器（BMP280、IMU）降低 BLE 解算維度（3D→2D）。**
2. **利用飛控姿態與推力資訊，提高 RSSI 資料可信度。**
3. **不增加任何定位硬體，維持低成本架構。**
4. **將定位結果整合至 Ground Station，供多飛控（ATK、XIAO nRF52840、XIAO ESP32S3）共用。**

---

# 最符合你研究方向的定位架構

```text
                 Flight Controller
         (IMU + BMP280 + Motor Thrust)
                     │
                     │
                     ▼
BLE RSSI ──► RSSI Calibration
                     │
                     ▼
            Outlier Removal
                     │
                     ▼
          Anchor Selection
                     │
                     ▼
      Weighted 2D Trilateration
                     │
                     ▼
          IMU Validation Gate
                     │
                     ▼
          Ground Station Position
```

## 這樣的定位模組有三個特色

* **符合你的研究主軸**：定位只是飛控系統整合的延伸，不會喧賓奪主。
* **充分利用你已完成的移植成果**：像是 `powerGetLastThrust()`、修正後的氣壓計、IMU 與姿態資訊，而不是另外引入全新的定位硬體。
* **具備工程價值**：在現有硬體條件下，透過資料校正、篩選與飛控資訊融合提升定位品質，這比單純套用「RSSI + Kalman + 三邊定位」更有說服力，也更符合你的論文方向。
